# 🚗 Android-Controlled IoT Robot Car

## 📌 Project Overview

The **Android-Controlled IoT Robot Car** is an embedded systems project developed using Arduino and Bluetooth communication. The system enables real-time wireless control of a robotic vehicle via an Android device while integrating obstacle detection and basic IoT security principles.

This project demonstrates practical implementation of:

- Embedded C firmware development  
- Bluetooth-based wireless communication  
- Sensor integration (Ultrasonic & IR)  
- Motor driver control using PWM  
- IoT communication security awareness  

---

- Embedded C

- Ultrasonic Sensor (HC-SR04)  
- IR Sensors

- Ultrasonic Sensor
- IR Sensors
- DC Motors with Chassis
- External Power Supply

---

## 🔄 Working Principle

1. Android device sends control commands via Bluetooth.
2. HC-05 module receives the signal.
3. Arduino processes the command using embedded C firmware.
4. Motor driver controls wheel movement accordingly.
5. Ultrasonic sensor detects nearby obstacles.
6. Robot performs collision avoidance when necessary.
